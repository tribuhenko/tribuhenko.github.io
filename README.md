# Tribu Henko V-120

Páginas de la Tribu Henko V-120 (VIVE Liderazgo).

- Registro de la tribu (Líder, Senior, SVT): https://tribuhenko.github.io/registro/
- Registro de la Oficina (Coordinador del PL, Entrenador, Personal administrativo): https://tribuhenko.github.io/oficina/
- Respuesta a las invitaciones (Sí voy · Quizás · No voy): https://tribuhenko.github.io/respuesta/ (se abre desde el correo)

La página guarda los registros en el Apps Script de la cuenta de la tribu. Este repositorio
no tiene datos de nadie: la lista de líderes, la base de datos y las fotos viven en Google.
